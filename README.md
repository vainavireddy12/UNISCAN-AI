# UniScan AI

UniScan AI is a multi-modal medical image analysis project developed
as a group project by three members.

## Team Members

- Vainavi Reddy
- Bagathi Navyasri
- Lahiri

## Project

The system combines medical imaging workflows to assist in generating
unified diagnostic reports from multi-modal medical images.

## My Contribution

As a team member, I contributed collaboratively to the development of
UniScan AI. My involvement included understanding the overall system,
working on the medical image processing workflow, assisting with the
application development and integration, testing the system, debugging
issues, and contributing to project documentation and presentation.
